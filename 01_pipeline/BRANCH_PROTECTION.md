# Protection de la branche main

Paramétrage conseillé dans GitHub :

- Pull Request obligatoire avant fusion.
- Interdire le push direct sur `main`.
- Exiger les checks `Tests Python 3.11`, `Tests Python 3.12` et `security-build`.
- Exiger une branche à jour avant fusion.
- Au moins une approbation si le contexte de l'épreuve le permet.

Faire une capture anonymisée de la configuration réellement appliquée.
